# Достоверность: числа, меры, источники, venue

Слайд читают как факт. Ошибка на слайде дороже пустого слайда: её повторят слушатели.

## Число — с условием и мерой

- **Условие идёт вместе с числом.** «Голова и softmax — 62% времени» верно для драфтера
  EAGLE у Llama-3-8B (один декодерный слой плюс полная голова) и чушь для модели 8B, где
  голова — около 7% читаемых весов. Слайд «What one step costs» стоял с 62% без условия,
  пока докладчик не поймал.
- **Мера называется прямо.** Доля весов, читаемых за шаг, ≠ доля времени шага: на малых
  моделях они расходятся в разы. Расчёт («время на ответ = токены × время шага»)
  помечается как расчёт, рядом с измеренными величинами, из которых он собран.
- **Агрегат — с набором, по которому он посчитан.** NF-CoT: 68.8 — среднее по пяти
  бенчмаркам, 80.0 — по четырём без LiveCodeBench; оба числа в статье есть.
- **Происхождение чисел чужого сравнения.** Если статья сравнивается с числами, взятыми
  из другой статьи (другой рецепт, другая длительность обучения, свой более слабый
  бейзлайн), это оговорка на слайде. Пример: LOTUS против KaVa — числа KaVa переписаны,
  KaVa учили LoRA, LOTUS — полным дообучением втрое дольше от CoT-чекпойнта.

## Сверка с источником

- **Каждое число на слайде сверено с первоисточником** — таблицей статьи, заметкой
  результата с провенансом. Не с памятью и не с пересказом.
- **Пересказ инструмента (WebFetch) — не источник.** Он дважды выдал неверное: смешал
  средние по разным наборам и придумал отсутствие таблицы. Таблицы читать из PDF:
  WebFetch сохраняет PDF в `tool-results/…pdf`, дальше PyMuPDF
  (`fitz.open(path)[page].get_text()`) и поиск по названию метода.
- **Карточка базы знаний — подсказка, где смотреть.** Перед слайдом — сверка по статье.
- **Свои замеры** — из заметки результата в волте, где указаны прогон и протокол. Нет такой
  заметки — сначала найти источник, а не ставить число.

## Venue

Формат строки: `Author et al., Venue Year — Title`. Venue пишется только подтверждённый.

1. `python scripts/venue.py <id> <id> …` — одним запросом поля `comments` и `journal_ref`
   с arXiv («Accepted to EMNLP 2025 main conference», «NeurIPS 2025», «ICLR 2026»).
2. Комментарий — зацепка. Подтверждение — страница конференции: proceedings, страница
   постера на `iclr.cc/virtual`, `neurips.cc`, `aclanthology.org`, `mlanthology.org`.
   Поиск: `"<точное название>" <конференция> <год>`.
3. Не подтвердилось — **только год**, без «arXiv»: `Tu et al., 2026 — …`.

Чем не пользоваться: Semantic Scholar показывает «arXiv» и у принятых статей; DBLP
быстро отвечает 429 на серию запросов. Venue соавтора проставляется в его же строке
ссылки (правка только текста «автор, год», формат его строки не трогать).

## Ссылка в чате

Любое упоминание статьи в ответе пользователю — с названием и ссылкой на PDF
`https://arxiv.org/pdf/<id>`; для не-arXiv — на страницу работы.
