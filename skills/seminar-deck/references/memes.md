# Мемы

Необязательная часть. Мем работает, когда подчёркивает вывод слайда, который ему
предшествует, а не украшает.

## Выбор
- Сначала предложить таблицей: слайд, что должно «щёлкнуть», мем, подписи. Вставлять
  после согласования; отклонённые не возвращать.
- Примерно один на блок, не больше двух в блоке; на чужие блоки — только по просьбе.
- Удачные пары из практики: «This is fine» — коллапс метода; «Is this a pigeon» —
  неверная категория («a deterministic vector» → «a policy action?»); «Always has been» —
  «метод на деле делает X»; Expanding Brain — эволюция подходов; Gru's Plan — план, который
  ломается на третьем шаге (повтор последней панели сам изображает петлю); Морфеус с двумя
  таблетками — финальный слайд.

## Шаблоны
- Источник — библиотека шаблонов imgflip: `https://api.imgflip.com/get_memes` (топ-100 с
  размерами и URL `i.imgflip.com/<id>.jpg`). Нет в топе — поиск
  `https://imgflip.com/memesearch?q=<запрос>` и страница шаблона
  `imgflip.com/memetemplate/<id>/<name>` (картинка — первая ссылка `i.imgflip.com`).
- **Скачивание — только с разрешения пользователя**: имя файла, источник, размер
  (`curl -sI` даёт Content-Length). Несколько кандидатов — скачать все, выбрать, лишние удалить.
- **Проверка и пересохранение:**
  `python scripts/img_check.py <файлы> --out-dir slides/figs/memes` — полное декодирование,
  ничего после конца картинки, нет сигнатур скриптов и архивов; затем пересохранение
  только пикселей в PNG. Два байта `MZ` внутри сжатых данных — случайность, не находка.

## Вставка
- Отдельный слайд сразу после содержательного: `d.meme(img, x, y, w, labels)`.
- Подписи — редактируемый текст, координаты в долях картинки. Белые подписи получают
  тёмную обводку (`outlined`); на светлых участках (доски у Gru) — тёмный текст без обводки.
- Положение элементов картинки (доски, колонки) найти по пикселям, а не на глаз: маска по
  цвету и перцентили координат. Длинную подпись разбивать `\n` вручную.
- Отрендерить и посмотреть каждый мем-слайд: подпись не закрывает лицо, не переносится
  по одному слову.
