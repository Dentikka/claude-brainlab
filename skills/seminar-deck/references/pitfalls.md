# Грабли python-pptx и PowerPoint

Каждая стоила времени хотя бы раз.

| симптом | причина | что делать |
|---|---|---|
| в подписях диаграммы `4,2` вместо `4.2` | числовой формат подписи берёт локаль Windows | подписи с дробью писать текстом: `bar_chart(decimals=1)`, `hbar_chart(labels=[…])` |
| над диаграммой надпись `share`/`v` | у одной серии PowerPoint рисует заголовок по имени серии | `chart.has_title = False` (в `hbar_chart` уже) |
| подпись столбца налезает на край | ось обрезается по максимуму значения | запас по оси (`maximum_scale = max · 1.25`) |
| логотип бледный на кремовом фоне | взят со слайда-разделителя (светлый вариант для тёмного фона) | брать логотип с контентного слайда |
| каракули или чужой шрифт на рендере | шрифта нет в системе | `fonts_check.py`; поставить в пользовательские шрифты + HKCU, перезапуск PowerPoint |
| `.potx` не открывается | тип содержимого «template» | `potx_to_pptx` |
| заметки не сохраняются / `notes_text_frame is None` | в шаблоне нет мастера заметок с телом | `ensure_notes_master`; в пустой Presentation мастер заметок создаётся только после первого обращения к `notes_slide` |
| заметка не встала | заметки ищутся по точному тексту заголовка | переименовал слайд — переименуй ключ в `NOTES` |
| после удаления слайдов файл тяжёлый или битый | удалён только `sldId` | `reorder()` — удаляет и связь (`drop_rel`) |
| `Device or resource busy` при записи | файл открыт в PowerPoint | писать `-new.pptx`, перенести после закрытия; PowerPoint не закрывать |
| строка ссылки в две строки | с venue строка удлинилась | сократить название (у составной строки — последнее название) |
| перенумерация блоков даёт дубли | замена «6→7» до «7→8» | менять с конца: 8→9, потом 7→8, потом 6→7; проверять число совпадений до записи |
| обводка подписи не видна | `a:ln` стоит после заливки в `rPr` | вставлять `a:ln` первым (`outlined` так и делает) |
| длинная сборка через heredoc в bash падает или портит регулярки | кавычки в теле; обратные слэши съедаются, `\r` в строке становится управляющим символом | файлы скриптов писать через Write, не heredoc |
| вывод python в консоль ломает кириллицу | cp1251 в pipe | запускать с `PYTHONUTF8=1` |
| рендер вызывает «Сохранить изменения?» | открытие не read-only | `Presentations.Open(path, ReadOnly=True, Untitled=False, WithWindow=False)`, только `Close()` |
| `Permission denied` при чтении колоды | файл открыт в PowerPoint у пользователя | собрать копию во временный файл и проверять её; окно пользователя не трогать |
| подпись серии легла на линию графика | подпись поставлена у конца линии | легенда в пустом углу графика |
| пунктир-ориентир наезжает на подписи значений | общая высота | убрать линию, число ориентира — в подпись или на панель рядом |
| стрелка рисуется точкой | нулевая длина (x1 == x2) | такую стрелку не рисовать |
| название обложки в две строки | длинное название блока | сократить название, кегль не трогать (`render.ps1`: `CHECK … title wraps`) |
| текст вылез из рамки, хотя у неё «подгонять по тексту» | PowerPoint подгоняет рамку только при правке текста, а сгенерированная остаётся как есть | рамку по тексту задавать в сборке; `render.ps1` ловит `CHECK … overflow` |
| `fonts_check` ругался на Aptos | шрифт темы мастера заметок из python-pptx | теперь это строка `notes`: слайдов не касается |
| QR со скриншота мутный | обрезан из рендера | вынуть исходную картинку из PDF прошлой колоды: PyMuPDF `page.get_images()` → `doc.extract_image(xref)` |

## Проверка перед сдачей

- рендер всех изменённых слайдов и их соседей, сетка — глазами; `render.ps1` без `CHECK`
  или с разобранными `CHECK`;
- `deck_check.py --outline`: число слайдов и порядок блоков, заметки, дата на титуле,
  формулировки;
- строки ссылок — отдельной полосой (`sheet.py --strip bottom`);
- `fonts_check.py` — без `MISSING`;
- заметки: сколько применилось (`apply_notes` возвращает число);
- PDF для раздачи — `render.ps1 -pdf`.
